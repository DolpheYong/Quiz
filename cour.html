1️⃣ Comprendre la Machine

Matériel (Hardware) vs Logiciel (Software)

🍳 Analogie de la cuisine Le Matériel, c'est la cuisine (les casseroles, le four, le plan de travail). Le Logiciel, c'est la recette de cuisine (les instructions pour préparer un plat).
Matériel (Hardware) Logiciel (Software)
Écran, clavier, souris Windows (système d'exploitation)
Unité centrale, imprimante Word, Excel, Chrome (applications)
Ce que l'on peut toucher Ce qui est invisible (code)
💡 Message clé On ne peut pas cuisiner sans cuisine, mais une cuisine sans recette ne sert à rien. L'ordinateur a besoin des deux pour fonctionner.

Le Système d'Exploitation (Windows)

C'est le chef d'orchestre de l'ordinateur. Il permet au matériel (clavier) de communiquer avec le logiciel (Word).

✅ Vérification rapide Pour voir la version de Windows : Paramètres → Système → À propos

2️⃣ Le Bureau et la Navigation

Le Bureau et la Barre des tâches

Le Bureau : c'est le plan de travail. On y place ce qu'on utilise souvent.

La Barre des tâches : c'est le tableau de bord de la voiture.

  • Icône Windows (Démarrer)
  • Zone de recherche
  • Applications épinglées
  • Zone de notification (heure, wifi, son) — souvent source de confusion pour les débutants
🎯 Astuce formateur Demandez aux apprenants de changer l'heure ou le volume. Ils manipuleront ainsi la zone de notification en toute sécurité.

Le Menu Démarrer

📖 Analogie C'est le sommaire d'un livre : toutes les applications y sont listées par ordre alphabétique.
🖱️ Action guidée Clic droit sur une application → Épingler à la barre des tâches pour un accès rapide.

Gérer les Fenêtres

Les 3 boutons magiques en haut à droite de chaque fenêtre :

Bouton Nom Fonction
− Réduire La fenêtre disparaît mais tourne en arrière-plan
□ Agrandir / Restaurer Plein écran ou taille moyenne
× Fermer Ferme la fenêtre (⚠️ vérifier la sauvegarde !)
⌨️ Raccourci puissant Windows + ← / → pour mettre deux fenêtres côte à côte. Idéal pour comparer deux documents.

3️⃣ L'Organisation des Fichiers

Dossier vs Fichier

🗄️ Analogie Le Dossier, c'est l'armoire. Le Fichier, c'est le document à l'intérieur.
⚠️ Règle d'or Un fichier a toujours un nom et une extension : .docx, .xlsx, .pdf, .jpg.
👁️ Afficher les extensions Onglet Affichage → cocher Extensions de noms de fichiers. C'est crucial pour la bureautique.

L'Explorateur de Fichiers

Le raccourci à retenir absolument : Windows + E

  • Volet gauche : lecteurs (C:, D:, clé USB), dossiers principaux (Bureau, Documents, Téléchargements)
  • Volet central : le contenu du dossier sélectionné
  • Barre d'adresse : le fil d'Ariane (où suis-je ?)
🛠️ Exercice guidé Créez ensemble un dossier « Formation_Bureautique » sur le Bureau, puis un sous-dossier « Vendredi ».

Les Opérations de Base

Action Méthode
Créer un dossier Clic droit → Nouveau → Dossier
Renommer Clic droit → Renommer (ou F2)
Sélectionner plusieurs Ctrl + clic
Tout sélectionner Ctrl + A
Copier / Coller (dupliquer) Ctrl + C / Ctrl + V
Couper / Coller (déplacer) Ctrl + X / Ctrl + V
Supprimer (corbeille) Suppr
Supprimer définitivement Maj + Suppr
⚠️ Attention Copier = dupliquer. Couper = déplacer. Ne pas confondre !

4️⃣ Bonnes Pratiques et Sécurité

Les 5 Raccourcis Indispensables

# Raccourci Action
1 Ctrl + C / V Copier / Coller
2 Ctrl + Z Annuler (le meilleur ami du débutant !)
3 Ctrl + S Sauvegarder (réflexe toutes les 5 min)
4 Alt + Tab Changer de fenêtre
5 Windows + D Afficher le bureau

La Règle d'Or de la Sauvegarde

💰 Analogie Ctrl + S est votre meilleur ami. C'est comme mettre son argent au coffre : tant que ce n'est pas sauvegardé, ce n'est pas en sécurité.
📦 Règle 3-2-1 simplifiée 3 copies du fichier, sur 2 supports différents, dont 1 hors site (cloud/OneDrive).

5️⃣ Atelier Pratique

🎯 Mission : « Le Dossier Parfait »

  1. Créez sur le Bureau un dossier nommé « Mon_Travail ».
  2. Ouvrez ce dossier.
  3. Créez à l'intérieur un sous-dossier « Documents » et un sous-dossier « Images ».
  4. Ouvrez Word, tapez « Bonjour, je m'appelle [Prénom] ».
  5. Sauvegardez le fichier sous le nom « Presentation.docx » dans le dossier « Documents ».
  6. Fermez Word.
  7. Ouvrez l'Explorateur (Windows + E) et vérifiez que le fichier est bien là.
  8. Renommez le fichier en « Ma_Presentation.docx ».
  9. Faites une copie de ce fichier et collez-la dans le dossier « Images ».
  10. Supprimez le fichier du dossier « Images » et videz la corbeille.

★ Conseils du Formateur

  1. Le rythme : allez lentement. Ce qui vous semble évident ne l'est pas pour eux. Faites-leur faire, ne le faites pas devant eux.
  2. Le vocabulaire : utilisez les termes techniques (curseur, bureau, dossier, extension) mais expliquez-les. Évitez le jargon trop complexe.
  3. L'erreur : déculpabilisez. « Si vous vous trompez, Ctrl + Z est votre ami ».
  4. L'analogie : utilisez des analogies physiques (armoire, cuisine, bureau).
  5. La vérification : à la fin de chaque partie, posez une question de contrôle.
